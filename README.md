- Using TypeScript

- Using Styled Components

- React Native

- Yarn

## Rules
1. Create a button component that can be used in different screen
2. Button can have different variants (primary, secondary, outline, etc.)
3. Button can have different sizes (small, medium, large)
4. Button can have different types (solid, outline, etc.)
5. Button can have different border radius (small, medium, large)
6. Button can have different padding (small, medium, large)
7. Button can have different color (primary, secondary, outline, etc.)
8. Button can be disabled
9. Button can have loading state
10. Button can have different icon positions (left, right)

- UI Kit Button component
